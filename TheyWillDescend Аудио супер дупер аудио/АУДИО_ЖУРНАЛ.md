# TheyWillDescend — Аудио супер дупер аудио

Журнал работ по аудио-системе. Обновляется по ходу разработки.

---

## Что сделано (сессия: переход на 120 аудио-зон + FMOD-интеграция)

### 1. Аудио-зоны вместо ячеек
- Удалены старые `AudioCell.cs`, `AudioCellSettings.cs`, `AudioGridManager.cs` (было 14 592 инстанса — перебор).
- Теперь **120 зон** = 12 угловых секторов × 10 дистанционных колец.
- Одна зона = конус 30° × кольцо ~12м (0–120м). Один FMOD Instance на зону.
- **Один инстанс на зону, не на ячейку** — 120 инстансов вместо 14 592.

### 2. Файлы системы
- `Presentation/Audio/AudioZoneSettings.cs` — ScriptableObject: секторы, кольца, дистанция, путь ивента, имя Distance-параметра, дебаг-логи.
- `Presentation/Audio/AudioZone.cs` — зона: FMOD-инстанс, 3D-атрибуты, RTPC, регистрация построек, Gizmos.
- `Presentation/City/AudioZoneManager.cs` — менеджер: строит 120 зон, тик видимости каждые 2 кадра, Distance-параметр + 3D каждый тик, загрузка банков, fallback-центр (0,0,0) если DOTS-сетка не готова 3 сек.
- `Presentation/City/AudioVisibilityChecker.cs` — проверка видимости: горизонтальный FOV (пересчёт из вертикального через aspect), forward выровнен по горизонтали.
- `Presentation/City/BuildingAudioSource.cs` — компонент на постройку: тип (House/Workshop/Market/...), activity weight, авто-регистрация в зоне.
- `Presentation/Audio/FmodBankLoader.cs` — загрузчик банков: Master + банки из поля Fmod Banks, кеш, BankLoadException → Warning.
- `Presentation/City/BuildingViewBoard.cs` — при спавне постройки регистрирует её в ближайшей зоне (`FindZoneNear`).

### 3. main_soundtrack отключён
- В `GameAudio` флаг `enableMusic` (по умолчанию **off**): `StartSessionMusic()` при off не запускает трек, `Awake()` принудительно глушит.
- `PlayingState` больше не вызывает `StartSessionMusic()` — только `StopSessionMusic()` на входе.
- Вернуть музыку: галка Enable Music в инспекторе GameAudio.

### 4. Ивент ambience_town привязан
- Путь ивента: `event:/audio/city/ambience_town` (в AudioZoneSettings).
- RTPC/параметры: `Has_Houses`, `Has_Workshops`, `Has_Market`, `Cell_Activity` (0–1), **Distance** (0–100, нормализация: метры / 120 × 100).

### 5. Логика звучания зоны (текущая)
- Зона звучит **только если**: (а) в поле зрения камеры, (б) в зоне есть постройки.
- Пустая зона — инстанс не создаётся. Снос всех построек — инстанс глушится сразу.
- 3D-позиция и Distance обновляются каждый тик видимости.
- Затухание по отдалению: 3D-позиция инстанса + Distance-параметр (audio LOD в FMOD Studio).

### 6. Дебаг
- Gizmos рисуются всегда (флаг Show Gizmos у AudioZoneManager).
- Цвета: ярко-зелёный — видна и звучит; жёлто-зелёный — видна, но FMOD-ивента нет; красный — мёртвое состояние (за камерой/пустая). Маркер-сфера: голубая — видна, красная — мертва.
- Логи ACTIVATED / DEACTIVATED (с пометкой no buildings), логи только один раз, не спам.

### 7. Исправленные баги
- `float3 != float3` возвращает `bool3` → заменили на `!math.all(a == b)`.
- Центры зон стояли на границах секторов → угол середины сектора `(Sector + 0.5f)`.
- Цвет зон не менялся за камерой → цвет завязан на `IsVisible` (геометрия), а не на `IsActive` (зависел от несуществующего FMOD-ивента).
- Зоны работали только у центра → горизонтальный FOV + выравнивание forward.
- Спам ошибок «Event not found» 14 592 раза → лог один раз.

## Что проверить в Unity / FMOD Studio (чек-лист)

- [ ] В FMOD Studio у ивента `ambience_town` включена **3D Spatialization** (иначе позиция игнорируется, звук «просто так»).
- [ ] Включён **Auto distance attenuation** у ивента (естественное затухание).
- [ ] Distance-параметр: диапазон **0–100**.
- [ ] Банк с ивентом собран (Ctrl+B), `.bank` лежит в `StreamingAssets/Desktop/`.
- [ ] Имя банка вписано в поле **Fmod Banks** у AudioZoneManager (без `.bank`).
- [ ] В `AudioZoneSettings.asset` путь ивента обновлён на `event:/audio/city/ambience_town` (старый путь зашит в ассете).
- [ ] В `BuildingViewBoard` заполнен слот **Audio Zone Manager**.
- [ ] На префабах зданий есть компонент `BuildingAudioSource` с указанным типом.
- [ ] В Scene View включена кнопка **Gizmos**.
