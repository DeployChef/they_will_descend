# 07. Плейбук агента

← [[00 Agent Brief]] | [[Index]]

Как вести работу, чтобы не смешать фазы и не оставить мир в промежуточном состоянии.

---

## 1. Перед любой фазой

- [ ] Прочитан [[00 Agent Brief]]
- [ ] Прочитан файл этой фазы
- [ ] `git status` чистый или пользователь знает, что вы стартуете поверх грязного дерева (сейчас поверх могут лежать 08 Ф5, 07 Ф6, 09 — не ваши)
- [ ] Play на текущем HEAD: меню → Game → дом → люди. Если уже красное — не ваша фаза, остановиться
- [ ] Grep «сейчас» из инвентаря ещё правда (файлы не переехали без вики)

---

## 2. Во время фазы

- Не начинать Ф(n+1), пока grep-ворота Ф(n) не зелёные.
- Не рефакторить Stories, VisualSet, FMOD, слайдеры пирамиды.
- Каждое структурное изменение компонента — сразу все сборки (Simulation + Presentation). Проект должен собираться в конце дня.
- Если застряли на Stories restore — не выдумывать очередь «на кадр». Прямая запись или явный вопрос пользователю.
- Unity: после смены компонентов дождаться компиляции, потом Play. Error Pause у пользователя включён — не оставлять лог Error.

---

## 3. Коммиты

Только по просьбе пользователя. Предлагать в конце фазы:

```text
Ф1: wipe/create рана, убрать фазы и despawn-очереди
Ф2: ссылки домов и агентов на Entity, int Id только сейв
Ф3: диспетчер не пишет DesiredWorkers, пауза не отпускает штат
Ф4: RequestSystems, один гейт SessionInGame
Ф5: HUD читает Entity и сводки
```

Не мешать в одном коммите «ещё поправил using» и логику, если это не хвост той же фазы.

---

## 4. Общий чек-лист Play (копия Brief)

1. Компиляция, консоль без ваших Error.
2. Меню → новая игра → поставить → штат → производство.
3. Снос с людьми и со стройкой.
4. Пауза здания, x1/x2/x3, Esc.
5. Сейв → меню → загрузка (дома, стройка elapsed, штат, вера, эра, истории).
6. Меню → новая игра без перезапуска Play. Нет двойных домов. Entities Hierarchy без прошлого рана.
7. Debug-сценарий: дома и люди видны сразу.
8. Хотя бы раз `GameBlockout.unity` — тот же функционал.

Известный шум, не чинить: `bus:/Ambience` NOT FOUND; Normal-сценарий kitchen `invalid cell c=100 r=7`; дороги пропадают в сейве.

---

## 5. Если сломали и не знаете что

| Симптом | Куда смотреть |
| --- | --- |
| Вечный loading 30 с | Ф1 не добит: кто-то ещё ждёт Phase/очереди |
| Второй ран с двойными людьми | Wipe не взял Prefab / агентов без RunScoped |
| После меню остались дома в ECS | Wipe не вызван из Shutdown; teardown GameEntry |
| NRE на Entity после сноса | нет HasComponent перед lookup |
| Все уволились по паузе | диспетчер ещё `desired = Paused ? 0` |
| Желание 5 стало 3 само | диспетчер ещё пишет DesiredWorkers |
| Сейв не грузит штат | SnapshotRestore не пишет Workplace; карта id→Entity пустая |
| Истории пустые после load | QueueRestore ждал Ready |
| Исследования пустые | Populate до Wipe или без RunScoped и wipe убил в том же кадре после |
| Клик по дому не выбирает | BuildingIdTag без Entity |
| Призрак/вид без модели | это 09 VisualSet, не эта перепись |

Откат: `git checkout` только файлов фазы. Не откатывать `Blockout/` и `#GameRun`.

## 6. Отчёт пользователю в конце фазы

1. Что сделано (список удаленных типов — ценнее списка «поправил файлы»).
2. Grep-ворота: какие пустые, какие нет и почему.
3. Что проверено в Play, что не проверяли.
4. Узкие места, которые всплыли и не описаны в файле фазы — дописать в файл фазы, не держать в чате.
5. Следующая фаза одной фразой. Не начинать её в том же ходе, если пользователь не сказал «продолжай».

## 7. Синхронизация канона (каждая фаза)

Минимум: статус в [[../07 Foundation Fixes]], пометка «сделано» в файле фазы этой папки, точечные правки Architecture из конца файла фазы.

Не переписывать 01–06 рефакторинга целиком. Они исторические. Ссылки `file:///f:/...` в них можно чинить, когда файл и так открыт.
