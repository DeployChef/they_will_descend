# 02 Gameplay Loop

← [[01 Design Pillars]] | [[Home]] | Далее → [[03 City & People]]

## Микро-цикл (сессия / день)

1. Считать состояние города: люди, запасы, тепло/жизнь, гнев богов
2. Назначить труд / приоритеты производства и дани
3. Реагировать на события и таймеры фазы
4. Закрыть ближайший кризис или купить время данью

## Макро-цикл (кампания / эпохи)

- Фазы требований богов ужесточаются
- Открываются новые постройки, законы, угрозы
- Город растёт — и становится хрупче
- Выбор концовки готовится накопленными решениями

## Ритм давления

| Слой | Пример |
| --- | --- |
| Короткий | голод, переполнение склада, сломанная цепочка |
| Средний | требование дани, буря / знамение, бунт |
| Длинный | фаза пирамиды, смена эпохи, финальный countdown |

> Срез: сутки в `GameTime.DayDuration` (~5 с) — для проверки тулзы. Боевая длительность дня — баланс, не хардкод в кнопке.
