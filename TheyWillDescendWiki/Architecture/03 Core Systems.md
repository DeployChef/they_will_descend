# 03 Core Systems

← [[02 Scenes & Lifetime]] | [[Index]] | Далее → [[04 Simulation]]

## Game Director

Оркестратор сессии: старт рана, фазы, пауза, win/lose, переходы.

## Event Bus

Явная шина доменных событий (данник получен, закон принят, кризис начался, житель умер…).

## Time / Phase Clock

- игровое время / день
- таймеры дани и кризисов
- связь с [[../GDD/05 Gods & Timeline|Gods & Timeline]]

## Audio Manager

Глобальный сервис на Root (как в джеме) — музыка, стингеры кризисов, VO.
