# 01 Первый пак

← [[00 Истории]] | [[Index]]

Первый пак для сценария, в котором на старте нет двух лесопилок. Сейчас это `DefaultScenario`: кухня и люди, лесопилок нет. В `DebugScenario` лесопилки уже две, и квест ниже закроется на следующем проходе, как только его запустят.

Тексты ниже — черновик. Падение веры в обоих жёстких выборах — **10**. Срок квеста — **24** игровых часа. Оба числа лежат на ассетах и меняются в инспекторе.

Болезни как состояния человека здесь нет. «Заболел» — текст диалога. Смерть — одна строка последствия, которая снимает агента под значком.

## Что пак требует от контракта

Уже дописано в [[00 Истории]]:

- факт «ран начался» и факт «наступила эра»;
- якорь «агент» — живой человек на площади;
- цель квеста «достроено N домов типа»;
- последствие «снять агента-якоря».

## Открытие

Триггер `run_start` слушает с первой минуты, политика `Once`, факт «ран начался». Запускает диалог `pyramid_intro`.

| | `pyramid_intro` |
| --- | --- |
| Показ | значок, тип «восклицание» |
| Якорь | штаб |
| Срок на открытие | 0, висит пока не кликнут |
| Текст | Пирамида кормит богов. Её надо кормить данью, иначе вера остынет |
| Пункт | `ok` — «Я понял». Запускает `sawmills_offer` |

Дальше значок уже не на пирамиде, а на человеке.

| | `sawmills_offer` |
| --- | --- |
| Показ | значок, тип «вопрос» |
| Якорь | агент на площади |
| Срок на открытие | 0 |
| Текст | Люди хотят работать. Нужно поставить лесопилки |
| `agree` | «Поставить». Запускает квест `build_sawmills` |
| `refuse` | «Не сейчас». Вера сразу −10. Число на эффекте, его можно поменять в ассете |

| | `build_sawmills` |
| --- | --- |
| Где | виджет квестов, строка слева внизу |
| Заголовок | Две лесопилки |
| Описание | Достроить две лесопилки за отведённое время |
| Цель | достроенных `sawmill` не меньше 2. Дом ещё в стройке не считается |
| Срок | 24 игровых часа. Ползунок на строке квеста. Число на ассете |
| Успех | диалог `sawmills_thanks` сразу на экран |
| Провал | список пустой: срок вышел — строка исчезает |

`sawmills_thanks` — сразу на экран, без значка. Текст: лесопилки стоят, люди вышли на работу. Один пункт `ok` — «Я понял», последствий нет.

Уже стоящие две лесопилки закрывают квест в тот же проход, как только он стал активен. Снос после успеха квест не открывает заново.

## Третья эра

Триггер `era_sick` слушает с первой минуты, политика `Once`, факт «наступила эра». Фильтр — третья эра сверху в `DefaultTimeline`, сейчас это `hunger` (после Dawn и Dusk). Если имелась в виду четвёртая строка `return`, фильтр меняется на неё.

| | `sick_worker` |
| --- | --- |
| Показ | значок, тип «восклицание» |
| Якорь | агент на площади. Это другой поиск, не тот человек, что был на предложении лесопилок |
| Срок на открытие | 0 |
| Текст | Этот человек заболел |
| `work` | «Заставить работать». Вера −10. Человек остаётся |
| `sacrifice` | «Принести в жертву». Снимается агент, на котором висит этот значок. Вера этой строкой не двигается |

Жертва бьёт того, кто привязан к диалогу в тик выбора. Если этот человек исчез раньше клика, значок уже сидит на другом, и умрёт тот, другой.

## Чего в паке нет

Роликов. Таймера на значках. Отдельного проигрыша квеста, кроме пустого провала по сроку. Запаса дерева как цели. Квест не требует назначить людей в лесопилки: успех — два достроенных дома.
